We're announcing an important security enhancement to the JKT48Connect system that affects all REST API users. To ensure better security and reliability of our services, we've implemented **mandatory IP whitelisting** for all REST API endpoints.

- **Reduce server load** from illegitimate requests

- **Provide better security** for all users

### For New Users

If you're new to JKT48Connect REST API, you'll need to complete the IP whitelisting process before you can access any API endpoints. This is a one-time setup that ensures secure access to all features.
